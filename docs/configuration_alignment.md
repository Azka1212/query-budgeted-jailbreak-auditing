## Protocol distinctions

The environment currently hardcodes a 128-token target request, despite 512-token adapter/config defaults. The historical transfer helper defaults to 200 episodes and does not explicitly pass Q=25. These scripts must not be presented as ready-to-run commands for the revised 50-objective, 512-token transfer experiment.

This revision includes a revised judge prompt and JSON-output changes that differ from v1.0.0. The manuscript prompt and the prompt used for each experiment must be versioned consistently; changes must not be retroactively attributed to earlier tables.

A local random seed is not proof that a decoding seed was sent to Ollama. The dedicated controlled-study client explicitly sends request seeds; the generic adapter does not.

## Reward accounting

For each variant, retain the latest valid rewrite and judge by pair_id (otherwise seed_id::operator). ASR = successful retained records / 93. Diagnostic Q/S = all 256 target calls / successful retained records. Success counts: binary 35, scalar 42, full5d 32. This differs from first-success objective-level accounting.

## Release policy

Use CSV for spreadsheet-compatible numerical results, Markdown for readable summaries, and LaTeX for paper tables. Do not include temporary run directories or publish pending values as final. Updating GitHub does not modify the already archived Zenodo v1.0.0 release.
